# Wanted: everything still to obtain or run

The project's single to-do list for evidence. Unlike `research-leads.md`, which
is a dated log of hunches, an entry here names **a document we do not have, a
search nobody has run, or a job on something already on disk**, says what it
would unblock, and says where to get it. **Delete an entry when it is done**
(the document is in `documents/`, the search has been run and its result
recorded where it belongs). Nothing done stays here.

Organised **by errand** — what you would be doing, and where — because that is
how items actually get obtained. Within a section, highest value first.

- **Library trips** live in `handbook/IN-PERSON.md`, not here: the Violé 1904
  map, Kimball's *Street Names of Los Angeles* (LAPL), the 1886–87 city
  directory lookups, the Huntington Solano-Reeve items, the seven people the
  title blocks named, and the never-tried L.A. Times / ProQuest / FIMo / UCI
  routes. Where an item below needs one of those, it says "→ IN-PERSON.md".
- **Method** (how to sweep a corridor, suffix decoys, known negatives, how to
  make an ordinance document) lives in `handbook/TRACT-RESEARCH.md` and
  `handbook/RENAMING-SOURCES.md`.

Consolidated 2026-09-21 from the five `shopping-list-2026-09-*.md` files,
`COMPILED-ORDINANCES.md`, `MINUTES-TO-CHECK.md` and `CDNC-QUERIES.md` (all
retired that day; git history has them), checked
item by item against the corpus (420 documents).

## 2. Newspaper and other browser searches

CDNC (`https://cdnc.ucr.edu`) is robots-blocked, so it needs a person or a
browser instance. Use the advanced-search form: phrase in quotes plus a date
range, newspaper = *Los Angeles Herald* unless noted. Article URLs:
`https://cdnc.ucr.edu/?a=d&d=LAH<YYYYMMDD>.<page>.<article>`. For a renaming,
search the ordinance's own formula ("an ordinance changing the name",
"changing the names of", "shall hereafter be known as") and **the successor
name first** (RENAMING-SOURCES.md Steps 2b, 2d). A hit is only usable if it
gives a cross street or a tract: capture the surrounding text.

## 5. County sheets, by corridor

**URL patterns** (DPW land records; downloads are Kenny's click, since
`pw.lacounty.gov` is unreachable from the sandbox):

- Misc Records: `https://pw.lacounty.gov/sur/nas/landrecords/misc/MR{bbb}/MR{bbb}-{ppp}.pdf`
- Map Book: `https://pw.lacounty.gov/sur/nas/landrecords/tract/MB{bbbb}/TR{bbbb}-{ppp}{suffix}.pdf`
- Parcel Map: `https://pw.lacounty.gov/sur/nas/landrecords/parcel/PM{bbb}/PM{bbb}-{ppp}.pdf`

So `MR066-064` is `…/misc/MR066/MR066-064.pdf` and `TR0013-048` is
`…/tract/MB0013/TR0013-048.pdf`. A multi-page ref is one file at its first
page. **Filenames below are exact, suffix included.** Everything in 5.1–5.10
was existence-checked when swept (2026-09-06 to 09-17). 5.11's Map Book
filenames were confirmed by Kenny on 2026-09-22: **all 33 resolved on the
filename as listed**, lettered and un-lettered alike, so the suffix recorded
from County layer 8's `REFERENCE` (TRACT-RESEARCH.md) needs no second-guessing.
A file resolving still says nothing about which filing it is; the title block
does. ★ = read first.
